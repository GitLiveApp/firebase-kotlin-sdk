A message received from, or (with Builder) sent to, Firebase Cloud Messaging, as the Android SDK's RemoteMessage. On Android the SDK delivers received messages to a FirebaseMessagingService; the other platforms receive messages through their own notification APIs, so there a RemoteMessage only comes from Builder.
