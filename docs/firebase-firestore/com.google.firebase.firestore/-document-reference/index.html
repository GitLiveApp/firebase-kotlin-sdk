A document location, mirroring com.google.firebase.firestore.DocumentReference from the Firebase Android SDK: the document may or may not exist; reads, writes and listeners are performed through it. A @Serializable class is written with the setData and updateData extensions, which map it through FirebaseFormat.Firestore on every platform; the SDK's set and update(Map), which map a class by reflection on Android, are deprecated with an error towards them.

Not mirrored: the Activity and Executor overloads of addSnapshotListener (see api/android-sdk/exclusions.txt).
