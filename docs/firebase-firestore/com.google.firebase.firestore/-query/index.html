A query over the documents of a collection or collection group, mirroring com.google.firebase.firestore.Query from the Firebase Android SDK: immutable, every method returns a new query with the constraint added.

Not mirrored: the Activity and Executor overloads of addSnapshotListener (see api/android-sdk/exclusions.txt).
