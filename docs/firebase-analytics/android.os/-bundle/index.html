Bundle

actual class Bundle : Parcelable(source)
expect class Bundle(source)

The subset of android.os.Bundle that Firebase Analytics events and default parameters are built from, so that Android code passing a Bundle to com.google.firebase.analytics.FirebaseAnalytics.logEvent compiles in common code.

On Android and the JVM this is a header stub that binds to the real class; on the other platforms it is a map. Values are strings, integral and floating-point numbers, booleans, nested bundles and arrays of bundles (the items parameter); the array is added with com.google.firebase.analytics.ParametersBuilder.param.
