The entry point of Firebase Analytics, mirroring com.google.firebase.analytics.FirebaseAnalytics; obtained with com.google.firebase.Firebase.analytics.

On Android this class is a header stub for the real one (its bytecode is deleted after compilation); on the other platforms it is real code over the platform SDK through an internal NativeAnalytics. On the JVM it is a no-op, as firebase-java-sdk has no analytics. The JS SDK has no session timeout, session ID or analytics data reset (sessions are managed by gtag): on JS and wasmJs setSessionTimeoutDuration and resetAnalyticsData do nothing, getSessionId completes with null, and the three carry @dev.gitlive.firebase.UnsupportedOnJs, so code compiled for JS gets a warning until it opts in.

The Event, Param and UserProperty names are compile-time constants in the Android SDK (static finals); here they are vals with the same values, as an expect declaration cannot be const. Compare, match and concatenate them as usual, but off Android they cannot initialize a const val or be an annotation argument.
