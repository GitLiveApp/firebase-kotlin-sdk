DatabaseReference

actual open class DatabaseReference : Query(source)
actual open class DatabaseReference : Query(source)
expect open class DatabaseReference : Query(source)

A location in the database that can be read and written, as the Android SDK's DatabaseReference. Values are the platform's natural types: Map, List, String, Boolean, Long and Double (and the platform SDK's own types on Apple platforms and JS). A @Serializable class is written with the setData and updateData extensions, which map it through FirebaseFormat.Database on every platform; the SDK's setValue and updateChildren, which map a class by reflection on Android, are deprecated with an error towards them.
