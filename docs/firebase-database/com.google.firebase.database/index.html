actual class MutableData

The data of a transaction as a JS value tree: the JS SDK's transaction receives the current value and returns the new one, so root holds the value being edited and each child refers to a path in it. A node with a priority is held in the SDK's { ".value": data, ".priority": priority } form, which every operation looks through. The tree is read and written through own properties only, so that a path such as __proto__ cannot reach the prototype chain.
