An immutable copy of the data at a location, as the Android SDK's DataSnapshot. value is the natural type of the data: a Map, a List, a String, a Boolean, a Long, a Double or null. A custom class is read with the reified getValue<T>() extension, which maps a @Serializable class with the Android SDK's rules on every platform; the SDK's reflective getValue(Class) and getValue(GenericTypeIndicator) are deprecated with an error on Android.

inline fun <T> DataSnapshot.getValue(): T?

The SDK's reified getValue, which maps a class by reflection on Android: deprecated with an error towards com.google.firebase.serialization.getValue, which maps through FirebaseFormat.Database on every platform (see DatabaseMapping.kt for why it lives in that package).

inline fun <T> DataSnapshot.getValue(): T?

The data as T, as the Android SDK's reified getValue, through the serializer of T with the Android SDK's rules (FirebaseFormat.Database, see databaseFormat) on every platform: a @Serializable class, a Map, a List or a primitive reads the same everywhere. It takes the place of the SDK's reflective getValue(Class) and of the SDK's own reified getValue<T>() (com.google.firebase.database.getValue), which is deprecated with an error.
