A point in time with nanosecond precision, mirroring com.google.firebase.Timestamp from the Firebase Android SDK.

The Date and Instant constructors, toDate and toInstant keep the SDK's signatures through the error-deprecated java.util.Date and java.time.Instant stand-ins and can only be called from Android/JVM code: from common code they fail to compile with a message naming the kotlin.time.Instant counterparts, the top-level Timestamp(Instant) function and toKotlinInstant. The Parcelable members are not mirrored.
