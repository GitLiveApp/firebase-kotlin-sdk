class Functions(val serializersModule: SerializersModule = EmptySerializersModule()) : FirebaseFormat(source)

Cloud Functions, following com.google.firebase.functions.Serializer.

convertToPlainValue accepts what the Android SDK accepts as call data: null, Boolean, String, any number, Lists and Maps with String keys; anything else throws an IllegalArgumentException (Object cannot be encoded in JSON: …). The Android SDK has no class mapping for Cloud Functions, so a class is only mapped through its serializer (encodeToPlainValue, decodeFromPlainValue), with its properties' serial names as they are and unknown properties ignored.

convertToPlainValue
Link copied to clipboard
fun convertToPlainValue(value: Any?): Any?

Converts value to plain values by its runtime type, as the Android SDK's mapper does with the Object given to calls such as DocumentReference.set(Object): plain values are checked and copied, the product's own value types are passed through and any other object is encoded with the serializer of its class, which must be @Serializable. The type arguments of a generic class are erased at runtime, so such a value goes through encodeToPlainValue, whose serializer knows them.

serializerFor
Link copied to clipboard
fun serializerFor(type: KType): KSerializer<Any?>

The serializer for type, where Any (as in Map<String, Any?>) stands for the plain value itself, as Object does for the Android mapper: it is decoded as is and encoded by its runtime type. The product's own value types are passed through the same way, and the type arguments of a generic class are resolved by this rule too. So is a type without a serializer of its own, such as the Comparable a map of mixed values infers, unless it is the base of a polymorphic hierarchy registered in the serializersModule.
