class PlainValue(val value: Any?)

A value a FirebaseFormat has already converted (the result of FirebaseFormat.convertToPlainValue or FirebaseFormat.encodeToPlainValue), which the formats pass through as it is: the com.google.firebase layers convert what they are given in one place and hand the result on to platform code that converts whatever it receives, so this marks the values that need no second pass.
