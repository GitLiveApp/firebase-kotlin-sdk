class File

Stands in for java.io.File so that the Firebase Android SDK members taking one (StorageReference.getFile(File)) can be declared in common code and deprecated with an error naming their multiplatform counterparts, which take a kotlinx-io Path (getFile(Path)). A value of this type cannot exist in common code: the class has no members and cannot be constructed. On Android and the JVM the class is a header stub that is stripped from the output (see buildSrc utils/HeaderStubs.kt), so code there uses the JDK's.
