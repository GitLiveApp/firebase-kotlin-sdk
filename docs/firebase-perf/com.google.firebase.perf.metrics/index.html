@Target(allowedTargets = [AnnotationTarget.FUNCTION])
annotation class AddTrace(val name: String, val enabled: Boolean = true)

Marks a method to be traced by the Firebase Performance Gradle plugin on Android, as the Android SDK's com.google.firebase.perf.metrics.AddTrace. It is a plain annotation on the other platforms, where nothing reads it.
