Firebase Performance Monitoring, as the Android SDK's com.google.firebase.perf.FirebasePerformance: the entry point for custom traces and HTTP metrics.

The JS SDK has no custom HTTP metrics (it records network requests itself), so on JS and wasmJs newHttpMetric returns a metric that reports nothing and carries @dev.gitlive.firebase.UnsupportedOnJs, so code compiled for JS gets a warning until it opts in.
