A reference to an object or folder in Cloud Storage, as the Android SDK's StorageReference. Files are given as android.net.Uri (the firebase-app stand-in off Android): a file: URL, or a path on Apple platforms. The members taking JDK types are declared through the error-deprecated java.io.File and java.io.InputStream stand-ins, pointing common code at the kotlinx-io getFile(Path) and putStream(RawSource) extensions (see StorageSources.kt).

putStream
Link copied to clipboard
fun StorageReference.putStream(source: <Error class: unknown class>): UploadTask

Uploads the bytes of source to this reference, closing it; the kotlinx-io form of putStream(InputStream). On Android and the JVM the SDK streams the source as it uploads; the Apple and JS SDKs upload whole buffers, so there the source is read to its end first (off the caller's thread on Apple platforms, at once on JS).
